**TODAY'S TASKS:**

**Task 1 — Suggest papers across 3 themes (approx. 30 minutes):**

I need papers in three specific areas. For each paper you suggest, provide:
- Full title
- Author(s)
- Approximate year of publication
- Venue/journal/conference (if known)
- 2-sentence description: what problem it addresses and what it found

**Theme A — ML-based network intrusion detection using NSL-KDD or similar datasets (3–4 papers)**
I need papers that show how machine learning is applied to detect network intrusions. Papers that use NSL-KDD are especially relevant.

**Theme B — Adversarial attacks on machine learning models in cybersecurity (3–4 papers)**
I need papers that demonstrate how adversarial inputs can fool ML-based security systems. Evasion attacks are most relevant.

**Theme C — Adversarial training as a defense for ML models (2–3 papers)**
I need papers on using adversarial training to improve model robustness.

**Task 2 — Honesty check (5 minutes):**
After giving me the paper list, explicitly flag:
- Any papers you are uncertain about (year, authors, or whether the paper exists)
- Any papers that are widely known vs. papers you are less sure about
- A reminder that I MUST verify every single paper on Google Scholar before using it

**Task 3 — Help me structure the verification (10 minutes):**
Give me a simple verification checklist I can use for each paper:
- How to search for it on Google Scholar
- What to check (title match, author match, year match, venue)
- What to do if I can't find it (exclude it, do not use AI-suggested alternatives blindly)

**Task 4 — Research gap preview (10 minutes):**
Based on the themes above, briefly describe what gap my project might address. Just a preliminary 2–3 sentence idea — we will finalize the gap in Week 2, Day 3.
